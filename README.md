## 📝 Descripción del Proyecto
Este proyecto es una aplicación de consola desarrollada en Java que simula una batalla entre dos ejércitos: el Bien y el Mal.
Cada ejército está compuesto por razas aleatorias con valores de valentía distintos. El usuario define la cantidad de combatientes por lado, y el sistema determina el bando ganador o si hay empate según la suma total de valentía.
El objetivo es practicar estructuras de datos, generación aleatoria, y lógica condicional de forma creativa y divertida.

## 💻 Desarrollo del Proyecto 
1. Java como lenguaje principal para la lógica de la simulación.
2. Generación aleatoria de razas mediante la clase Random.
3. Comparación de puntajes para determinar al ganador.
4. Diseño modular: cada grupo de razas se encuentra encapsulado en clases o estructuras diferenciadas.

### 🛠️ Lenguajes y Tecnologías
- **Java:** Lenguaje principal del proyecto.
- **JDK 17+:** Recomendado para compilación y ejecución.
- **IntelliJ IDEA:** Opcional para facilitar el desarrollo.
<br><br>


## ⚙️ Sistema de Puntuación
### 🟢 Razas del Bien
- Pelosos → 1
- Sureños Buenos → 2
- Enanos → 3
- Númenóreanos → 4
- Elfos → 5

### 🔴 Razas del Mal
- Sureños Malvados → 2
- Orcos → 2
- Goblins → 2
- Huargos → 3
- Trolls → 5
